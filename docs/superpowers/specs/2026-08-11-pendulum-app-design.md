# Pendulum App Design

## Goal

Add a fourth app, "Pendulum", to the multi-app firmware: an interactive single-pendulum
physics simulation. The user drags the bob to set a starting angle, releases it, and
watches it swing and damp to rest under a simplified gravity+damping model.

## Non-goals

- Not a real-world-accurate physics engine (no literal gravity/length units) — constants
  are chosen and tuned for a visually pleasing swing, same spirit as a decorative desk toy.
- No double pendulum / chaos mode, no persisted state, no network/storage layer.

## Architecture

New directory `main/apps/app_pendulum/`, following the same shape as `app_stopwatch`:

- `app_pendulum.h` / `app_pendulum.cpp` — `mooncake::AppAbility` subclass. Owns the
  `input::KeyManager`, runs the physics integration in `onRunning()`, and forwards
  drag/release events from the view into the physics state.
- `view/view.h` / `view/view.cpp` — `PendulumView`: builds the panel, title, pivot dot,
  rod (`Line` widget), and bob (`Container` circle). Exposes `setAngle(double radians)`
  to reposition rod+bob, and exposes drag state via `consumeDragAngle()` (returns the
  touch-driven angle while dragging) and `consumeReleaseRequested()` (true the frame the
  user lets go).

Registered in `main/main.cpp` alongside the other apps:
`GetMooncake().installApp(std::make_unique<AppPendulum>());`

New launcher icon `main/assets/images/icon_pendulum_app.c` — 200×200 `LV_COLOR_FORMAT_RGB565`,
matching the exact format of the existing `icon_todo_app.c`/`icon_stopwatch_app.c`
(confirmed via their headers: `.header.cf = LV_COLOR_FORMAT_RGB565`, `w=200 h=200`,
`data_size = 40000*2`). Generated by a small standalone Python rasterizer (no new
dependencies — draws the same pivot/rod/bob glyph as the app itself) rather than an
external image-conversion tool, since no such tool/pipeline exists in this repo already
(the existing icons predate this session and their generation script isn't present).

## Physics Model

Standard damped pendulum ODE, integrated with semi-implicit (symplectic) Euler each
`onRunning()` tick:

```
theta'' = -omega0_sq * sin(theta) - damping * theta'
```

- `dt` = time since last tick (from `GetHAL().millis()`), capped at 50ms so a stalled
  frame can't blow up the integration.
- `omega0_sq` (rad²/s²) and `damping` (1/s) are tuned constants, not derived from a
  literal pixel-length/gravity pair. Starting point: `omega0_sq ≈ 6.8` (~2.4s period),
  `damping ≈ 0.15` (settles in roughly 15-20s) — exact feel to be tuned empirically once
  running on hardware, same as Stopwatch's layout was iterated after first flash.
- While the user is dragging, physics integration is skipped entirely and the angle is
  driven directly from touch position.

## Interaction

- **Drag**: `LV_EVENT_PRESSED` / `LV_EVENT_PRESSING` registered on the whole panel (so the
  user doesn't have to land precisely on the rod/bob to start a drag) compute
  `theta = atan2(dx, dy)` where `dx = touch.x - pivot.x`, `dy = touch.y - pivot.y` (pivot
  fixed near the top of the panel, bob hangs below). Clamped to ±80° so the rod can't
  flip past horizontal. Matches the existing touch-point pattern used in
  `app_moments/view/view.cpp` (`lv_indev_get_point`).
- **Release**: `LV_EVENT_RELEASED` marks the drag as finished; physics resumes from the
  released angle with zero angular velocity.
- **Re-drag anytime**: dragging is allowed whether the pendulum is mid-swing or at rest —
  no separate "grab" gesture is required.
- **BtnA** (`KeyEvent::GoPrevious`): reset to a default 45° angle, zero velocity, restart
  the swing — same button convention as Stopwatch's primary action.
- **BtnB**: unbound (not every app needs both buttons — Todo and Moments only use touch).
- **Hold both buttons**: `KeyEvent::GoHome`, closes the app — standard across all apps,
  handled automatically by `KeyManager`.

## Visuals

- White background panel (`0xFFFFFF`), 466×466, matching Todo's theme.
- Title "Pendulum", reusing the already-compiled `TodoTitleBold40` font (ASCII-only, no
  need for a new font asset), positioned near the top like Todo's/Stopwatch's titles.
- Fixed pivot: small dark dot anchored below the title.
- Rod: `uitk::lvgl_cpp::Line`, two points recomputed every frame from `theta`
  (`bob = pivot + L * (sin(theta), cos(theta))`), dark gray, ~4px wide.
- Bob: circular `Container` (`setRadius(LV_RADIUS_CIRCLE)`), positioned via `align`/`setPos`
  each frame, filled with the existing accent blue `0x5865F2` used elsewhere for
  dialog/confirm affordances.

## Edge Cases

- App open/close: view and key manager are created in `onOpen()` and torn down in
  `onClose()`, same lifecycle as Stopwatch/Todo — no persisted state to reload.
- Drag starting exactly at the pivot (`dx=0, dy=0`): guard against `atan2(0,0)` by simply
  ignoring the update for that frame (keep the previous angle) rather than producing a
  NaN/undefined angle.
- Rapid re-drag mid-swing: since dragging fully overrides `theta` every frame and zeroes
  `omega` only on release, there's no special-casing needed — the integration loop just
  resumes naturally from wherever the drag left off.
